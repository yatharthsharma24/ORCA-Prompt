- run_sql: Run one read-only SQLite SELECT across any tables (joins, CTEs, CASE allowed). Use when query_data cannot express the question.
  Example input: {"sql": "SELECT f.year, f.landings_tonnes, ROUND(AVG(o.chlorophyll_mg_m3),3) AS monsoon_chl FROM fish_landings f JOIN ocean_monthly o ON o.year = f.year - 1 WHERE f.state='Kerala' AND f.scientific_name='Sardinella longiceps' AND o.region='SE Arabian Sea' AND o.month BETWEEN 6 AND 9 GROUP BY f.year ORDER BY f.year"}
- trend: Fit a yearly trend to a series spec {"dataset": id, "metric": column, "agg": "avg|sum|min|max", "where": {...}} aggregated to one value per year. Returns OLS slope per year and per decade, r2, p-value, Mann-Kendall test and Sen's slope. Optional start_year/end_year.
  Example input: {"dataset": "D-OCEAN", "metric": "sst_c", "agg": "avg", "where": {"region": "Lakshadweep Sea"}}
- anomaly: Compare values with a baseline climatology. mode 'annual' (default): yearly anomalies and z-scores for a series spec {"dataset": id, "metric": column, "agg": "avg|sum|min|max", "where": {...}} aggregated to one value per year. mode 'monthly': flags months above the baseline 90th percentile of that calendar month (a monthly marine-heatwave approximation). 'baseline' is [start_year, end_year].
  Example input: {"dataset": "D-OCEAN", "metric": "sst_c", "agg": "avg", "where": {"region": "Andaman Sea"}, "baseline": [2004, 2013], "mode": "monthly"}
- calculate: Evaluate arithmetic on numbers taken from earlier observations (percent change, ratios, differences). Every derived number you report must come from this tool or another tool. Do not use thousands separators.
  Example input: {"expression": "(48670 - 390830) / 390830 * 100", "label": "percent change in Kerala oil sardine landings 2013 to 2016"}
